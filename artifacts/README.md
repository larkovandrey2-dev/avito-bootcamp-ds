# Артефакты final v4

В Git хранятся только маленькие файлы:

- `final_v4_e4_yetirank.cbm` — CatBoost YetiRank, около 180 КБ;
- `final_v4_feature_schema.json` — точный порядок 185 признаков;
- `final_v4_config.json` — источники кандидатов, параметры и метрики.
- `retrieval100_sampler.joblib` — маленькая вспомогательная модель для повторения выбора обучающих отрицательных примеров.

Модель маленькая, поэтому Git LFS не нужен. Она служит удобством: полный запуск умеет переобучить её из исходных данных и кэша признаков.

Большие веса текстовой модели сюда не копируются. При отсутствии локального кэша `sentence-transformers` загрузит `ai-sage/Giga-Embeddings-instruct-480M-0826` из Hugging Face.
